# JavaScript Internship Assignments

## About
This repository contains six practical assignments completed as part of my JavaScript internship. The assignments cover fundamental JavaScript concepts, with code examples for each topic.

## Assignments

1. **Variables, Data Types, and Console Operations** — Declaring variables and checking data types using `typeof`.
2. **Operators, Expressions, and Input Handling** — Accepting user input, converting data types, and calculating a bill with a tip.
3. **Conditional Logic Implementation** — Using `if...else`, `switch`, and the ternary operator.
4. **Loop Control Structures** — Practicing `for`, `while`, and `do...while` loops, including `break` and `continue`.
5. **Function Architecture and Scope** — Using standard functions, arrow functions, default parameters, and block scope.
6. **Arrays, Objects, and Core Methods** — Working with product objects and using `forEach()`, `filter()`, and `map()`.

## Requirements
- Node.js for running the `.js` files.
- A web browser for running `assignment2.html`.

## How to Run

For JavaScript files, open a terminal in the project folder and run the relevant command:

```bash
node assignment1.js
node assignment3.js
node assignment4.js
node assignment5.js
node assignment6.js
```

For Assignment 2, open `assignment2.html` in a browser and enter the requested values in the prompts. Open the browser console to view the output.

## Learning Outcomes
- Understand JavaScript variables and data types.
- Perform calculations using operators.
- Apply conditions and loops.
- Define functions and understand variable scope.
- Manipulate arrays and objects using built-in methods.
